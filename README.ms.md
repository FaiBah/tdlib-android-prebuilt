## Gambaran Keseluruhan

Repositori ini menyediakan binari TDLib prebuilt untuk Android, tanpa perlu mengkonfigurasi NDK, CMake, OpenSSL, atau persekitaran binaan berasaskan Docker. Artifak prebuilt boleh didapati di bawah [Releases](../../releases).

---

## Lesen

TDLib dilesenkan di bawah [Boost Software License 1.0](https://github.com/tdlib/td/blob/master/LICENSE_1_0.txt).

Repositori ini hanya mengautomasikan pembinaan dan pengedaran binari prebuilt. Ia tidak mengubah suai atau mengedar semula kod sumber TDLib yang telah diubah suai.
