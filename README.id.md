## Ikhtisar

Repositori ini menyediakan binary TDLib prebuilt untuk Android, sehingga Anda tidak perlu mengonfigurasi NDK, CMake, OpenSSL, atau lingkungan build berbasis Docker. Artefak prebuilt tersedia di halaman [Releases](../../releases).

---

## Lisensi

TDLib dilisensikan di bawah [Boost Software License 1.0](https://github.com/tdlib/td/blob/master/LICENSE_1_0.txt).

Repositori ini hanya mengotomatisasi proses build dan distribusi binary prebuilt. Repositori ini tidak memodifikasi atau mendistribusikan ulang source code TDLib yang telah diubah.
