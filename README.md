# TDLib Android Prebuilt

Prebuilt [TDLib](https://github.com/tdlib/td) binaries for Android, compiled automatically via GitHub Actions and published on a schedule.

No need to set up NDK, CMake, OpenSSL, or a Docker build chain yourself — grab a ready-to-use artifact from [Releases](../../releases).
