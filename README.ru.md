## Обзор

Этот репозиторий предоставляет готовые бинарные файлы TDLib для Android, избавляя от необходимости настраивать NDK, CMake, OpenSSL или среду сборки на основе Docker. Готовые артефакты доступны в разделе [Releases](../../releases).

---

## Лицензия

TDLib распространяется по лицензии [Boost Software License 1.0](https://github.com/tdlib/td/blob/master/LICENSE_1_0.txt).

Этот репозиторий только автоматизирует сборку и распространение готовых бинарных файлов. Он не изменяет и не распространяет изменённый исходный код TDLib.
