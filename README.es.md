## Descripción general

Este repositorio proporciona binarios precompilados de TDLib para Android, eliminando la necesidad de configurar NDK, CMake, OpenSSL o un entorno de compilación basado en Docker. Los artefactos precompilados están disponibles en la sección [Releases](../../releases).
